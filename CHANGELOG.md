# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 — 2026-09-10

- Refined the project into a clean educational framework for algorithmic fairness analysis.
- Implemented modular fairness evaluation, benchmark, and reproducibility workflows across classification models.
- Preserved leakage-prevention, evaluation-integrity firewalls, cluster-aware bootstrap uncertainty, and causal DAG safeguards.
- Added standard MIT licensing and public project metadata.
- Simplified documentation into domain-focused educational guides and unified CLI usage (`afa {demo,benchmark,ingest,audit}`).
- Clarified dataset, proxy-attribute, causal, and fairness-metric screening limitations.
